# Product Catalog

Catalog schema: 1

This catalog is a product-navigation projection, not a second decision authority. Linked tracker items remain canonical for product answers, evidence, validation state, specifications, and implementation status.

The catalog starts empty. Do not predefine a complete function tree during initial setup or early Wayfinder discovery. Add a stable capability only after its product boundary is clear.

A catalog node is a Markdown heading followed by:

- `Catalog ID:` a stable, unique identifier using letters, numbers, dots, dashes, or underscores;
- `Phase:` the product phase, when known;
- `Summary:` one navigation-level sentence;
- `Sources:` Markdown links to canonical decisions, specifications, or implementation tickets.

Heading depth defines parent-child hierarchy. Open or claimed product tickets without a stable mapping appear automatically in the Board's Exploration section.
