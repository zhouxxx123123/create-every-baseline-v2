# Learn Baseline 中文学习指南

这是一个虚构的安全练习仓库，不连接远端、不包含真实账号或客户数据，也不会修改你的真实项目。

## 你会怎样学习

每个 checkpoint 都按同一节奏进行：

1. 教师只解释当前动作需要的概念；
2. 你在本练习仓库中完成一个可检查的动作；
3. 使用 `submit` 提交证据，此时还不算通过；
4. 教师检查实际内容并记录 `pass` 或 `retry`；
5. 一条 track 的全部 checkpoint 通过后，还要进行一次综合评分。

## 三种状态

- `submitted`：作业已经存在，等待检查；
- `needs-revision`：需要按具体反馈修改；
- `accepted`：当前 checkpoint 已达到验收条件。

只有全部 checkpoint 为 `accepted`，并且 track 评分通过，课程才会把该 track 记为完成。

## 术语

- **Skill practice**：本课真正操作的 Skill，可以计入实操能力；
- **Reference-only**：只学习它的用途、边界或兼容关系，不代表已经会操作；
- **Evidence**：能被教师实际检查的文件、命令输出或行为结果；
- **Resume target**：中断或绕行后应准确返回的位置；
- **Stop condition**：出现后必须停止当前流程并返回权威来源的条件。

## 安全边界

默认只在本练习仓库内工作。GitHub、部署、账号、生产环境和外部 tracker 写入保持模拟状态，除非你另行明确要求真实操作并确认范围。
