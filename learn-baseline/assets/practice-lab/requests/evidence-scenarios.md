# Evidence Routing Scenarios

Classify each uncertainty as product decision, external research, prototype validation, or technical spike.

1. Should dismissing a review reminder change the Review Request state?
2. How do current enterprise work-management products distinguish reviewer responsibility from notification delivery?
3. Can users reliably understand the difference between "review assigned" and "reminder delivered" in the proposed interaction?
4. Can the target desktop API safely suspend an upload without corrupting the local file?
5. Should a reviewer without Project access receive a controlled exception or be rejected?
6. Does the existing product baseline already define where archived Tasks remain discoverable?
