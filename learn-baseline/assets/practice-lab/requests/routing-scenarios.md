# Routing Scenarios

For each scenario, choose the smallest canonical skill or flow that owns the unresolved outcome.

1. The team knows it wants a cross-project review queue, but cannot agree on who owns a review, how users recover missed work, or whether the queue is a new object.
2. The product behavior is confirmed, but nobody knows whether the operating-system API can safely pause and resume the required local operation.
3. A current readiness receipt exists for one bounded feature and the team wants a publishable specification.
4. A customer reports that a rejected Task rename still changes the Task, but no test reproduces it.
5. A developer understands the local module but wants a higher-level map of callers and neighboring modules.
6. A long thread must move to a fresh session for a two-hour research detour and later return to one exact product question.
