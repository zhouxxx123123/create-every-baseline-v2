# Feature Request: Shared Review Queue

Teams want one place to see work that needs review across several Projects.

Current proposal:

- show every Task that "needs attention";
- let AI decide which items are important;
- create a reminder and a to-do for every review;
- allow reviewers to open the Task even when they cannot enter its Project;
- keep the queue available across Workspaces.

The request does not define Review Request identity, responsibility, access prerequisites, recovery location, lifecycle, or data-boundary behavior.
