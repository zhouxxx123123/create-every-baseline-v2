# Harbor Tasks Practice Lab

This fictional repository is a safe workspace for the Learn Baseline academy. It contains intentionally incomplete product context and one small code defect.

中文学习者请先阅读 `LEARNER-GUIDE.zh-CN.md`。教师会按进度文件中的语言偏好讲解，但 Skill 名称、checkpoint ID、命令和文件路径始终保持原文，方便复现。

Use it to practice:

- workflow routing;
- product decisions and domain modeling;
- research, prototype, and technical-spike contracts;
- readiness, specification, ticketing, implementation, and review;
- bug diagnosis, triage, architecture analysis, and skill authoring.

The lab has no remote, credentials, production data, or required write-capable external service. The optional research track may read current public primary sources, but it must not sign in, publish, or write externally. Do not add real secrets or customer information.

Learner evidence belongs in `learner-artifacts/`. Course progress belongs in `.learn-baseline/`.
